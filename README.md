# TaxFlow UK production website

Updated: 6 October 2026

## Included

- 34 working calculators
- 20 tax blog articles
- 23 pages covering other UK taxes and duties
- Dark black and charcoal design
- Green buttons and active states
- Poppins font
- Installable web app
- Install popup
- Service worker and offline page
- PWA icons
- Search and category filters
- Internal links between calculators, articles and tax pages
- Sitemap and robots file
- Hostinger Apache settings

## Upload

Upload the contents of this folder to public_html.

The installable web app requires HTTPS. Make sure SSL is active on the live domain.

## Before launch

1. Replace the provisional domain https://www.taxflowuk.co.uk if the final domain is different.
2. Replace hello@taxflowuk.co.uk if the contact email is different.
3. Add analytics or advertising only after your privacy and consent setup is ready.
4. Run final calculator examples against HMRC tools or professional tax software.
5. Re-check rates after a Budget, fiscal statement or HMRC update.

## Property taxes

- SDLT is used for England and Northern Ireland.
- LBTT is used for Scotland.
- LTT is used for Wales.
